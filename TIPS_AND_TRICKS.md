## 🎨 Design Secrets

### Chat Bubble Colors
Each user gets a consistent color based on their user ID:
- **Algorithm**: Hash of user ID → Color index
- **Result**: Same user = Same color always
- **Your messages**: Always purple→pink gradient
- **Others**: Unique gradient per person

### Rainbow Audio Wave
- **50 frequency bars** analyzed in real-time
- **Color formula**: `hue = (index / 50) * 360°`
- **Height**: Based on audio amplitude (0-255)
- **Update rate**: ~60 FPS for smooth animation
- **Gradient**: Each bar has 2-color gradient
