# 🚀 Dreamland - Quick Start Guide

## Get Up and Running in 2 Minutes!

### Step 1: Start the Development Server
```bash
npm run dev
# or
pnpm dev
```

### Step 2: Open in Browser
Navigate to `http://localhost:5173`

### Step 3: Sign In
- Use **any email** and **any password**
- Example: `demo@test.com` / `password123`
- Click "Sign In"

## 🎮 Try These Features Now!

### Chat Features
1. **Send a Message**: Type in the input box at the bottom
2. **Reply to Message**: Hover over any message → Click reply icon (↩️)
3. **React with Emoji**: Hover over message → Click smile icon 😊 → Pick emoji
4. **View Profile**: Click on any user's circular avatar
5. **Edit Your Profile**: Click your avatar → Click "Edit Profile"
6. **Create a Group**: Click the Users icon (👥) in top-left of chat list
7. **Customize Background**: Click three dots (⋮) → "Customize Chat"
8. **Record Voice**: Click microphone icon → Watch rainbow wave!

### Profile Management
- **View**: Click any avatar in chat
- **Edit**: Click "Edit Profile" button
- **Change Avatar**: Click camera icon when editing
- **Update Bio**: Add your description

### Install as App (PWA)
- **Look for the green "Install App" button** in the sidebar
- Or use your browser's install prompt
- Works on iPhone, Android, Desktop!

## 🆘 Quick Troubleshooting

**PWA install button not showing?**
- Try in Chrome/Edge (best PWA support)
- Check browser console for errors
- Service worker needs HTTPS in production

**Chat not loading?**
- Check browser console
- Refresh the page
- Clear browser cache

**Can't edit profile?**
- Make sure you're viewing YOUR profile
- Look for "Edit Profile" button
